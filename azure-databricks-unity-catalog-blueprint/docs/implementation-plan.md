# Implementation Plan

## Delivery Stages

1. Define Entra groups, workspaces, data domains, and environment boundaries.
2. Create catalog and schema conventions.
3. Add managed storage and external location examples.
4. Implement least-privilege grants.
5. Add workspace binding and isolation guidance.
6. Implement row filter and column mask examples.
7. Add audit queries, lineage review, cleanup, and access recertification.

## Key Assets

- SQL catalog and schema setup.
- Storage credential and external location templates.
- Group grant scripts.
- Row filter and mask functions.
- Permission test matrix.
- Audit and lineage queries.
- Environment and cleanup guidance.

## Acceptance Criteria

The blueprint becomes Active when a learner can provision the fictional domain, prove allowed and denied access, inspect masked values and lineage, and remove the sample safely.
