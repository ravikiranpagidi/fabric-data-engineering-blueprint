# Diagram Brief

**Title:** Unity Catalog Isolation And Fine-Grained Access Model

**Nodes:** Entra groups, Dev and Prod workspaces, metastore, catalogs, schemas, managed storage, storage credential, external location, tables, volumes, filters, masks, audit, lineage.

**Flow:** Groups receive data privileges, workspaces bind to approved catalogs, locations govern storage, and policies control query results.

**Layout:** Identity left, workspace and metastore center, data and storage right, audit below.
