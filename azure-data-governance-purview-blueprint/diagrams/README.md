# Diagram Brief

**Title:** Governed Data Product Discovery And Access Workflow

**Nodes:** Data estate, ingestion, catalog and map, glossary, classifications, owners, stewards, access workflow, consumers, evidence register.

**Flow:** Metadata and lineage enter the catalog. Owners add context. Consumers discover a product, review classification, request access, and receive governed platform access.

**Layout:** Data estate left, governance services center, people and workflows right.
