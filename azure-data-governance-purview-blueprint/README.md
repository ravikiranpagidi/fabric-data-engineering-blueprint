# Azure Data Governance And Microsoft Purview Blueprint

> Establish a practical governance operating model for discoverable, owned, classified, and traceable data products.

## Status

**Planned scaffold**

This folder contains the implementation contract. Product-specific configuration will be verified when active development starts.

## Business Scenario

A fictional Fabrikam Retail Data Office needs consistent discovery, ownership, glossary, classification, lineage, access review, and governance issue handling across data domains.

## Microsoft Services

- Microsoft Purview governance capabilities
- Microsoft Fabric
- Azure Data Factory
- ADLS Gen2
- Power BI
- Microsoft Entra ID
