# Diagram Brief

**Title:** Governed Conversational Analytics With Fabric Data Agent

**Nodes:** Business user, data agent, instructions, Lakehouse, Warehouse, semantic model, KQL Database, permission enforcement, query execution, diagnostics, evaluation, feedback.

**Flow:** The user asks a question. The agent selects an approved source, applies user permissions, generates a read query, returns a concise answer, and records diagnostics.

**Layout:** Request flow across the center, governed data sources below, evaluation and lifecycle above.
