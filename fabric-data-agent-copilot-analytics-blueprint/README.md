# Fabric Data Agent And Copilot Analytics Blueprint

> Prepare governed Fabric data products and semantic models for reliable conversational analytics.

## Status

**Planned scaffold and preview-dependent**

Current feature availability, capacity requirements, supported data sources, lifecycle support, and limitations must be verified when implementation starts.

## Business Scenario

A fictional Northwind Service Operations team wants governed business Q&A over service cases, parts, technicians, regions, service-level events, and customer satisfaction.

## Microsoft Services

- Microsoft Fabric data agent capabilities where available
- Fabric Lakehouse and Warehouse
- Power BI semantic models
- KQL Database
- Microsoft Purview controls
- Microsoft Entra ID
- Fabric Git integration and deployment pipelines where supported

## What Learners Will Build

1. Agent-ready governed data source.
2. Business instructions and approved example questions.
3. Semantic definitions and query validation.
4. Permission and RLS behavior tests.
5. Question-answer evaluation set.
6. Diagnostics and feedback workflow.
7. Lifecycle and support checklist.
